# Cloud Cover art v2

Second pass of the HushSwap launch art, steered by the cloud-era reference board (golden hour, rainbow light,
liquid chrome, pearl orbs, dream haze, film grain). The reference board itself is not included here.

- Images generated with GPT Image 2.5 (via Figma) from `style-block.txt`, then finished by hand: 6–8% monochrome grain,
  and for posts the real logo (`lockup-horizontal-cream`), frosted card and exact copy set on top. No text is AI-generated.
- Posts: 6 posts × 1:1, 4:5, 9:16. Captions and alt text in `captions-alt.md`.
- Everything outside `v2/` is the first pass and is unchanged.
